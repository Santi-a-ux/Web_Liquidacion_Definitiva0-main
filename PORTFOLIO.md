### 1. 🏆 **Sistema de Liquidación Laboral / Employee Severance Calculator**
[![Stars](https://img.shields.io/github/stars/Santi-a-ux/Web_Liquidacion_Definitiva0-main?style=social)](https://github.com/Santi-a-ux/Web_Liquidacion_Definitiva0-main)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**Repositorio:** [Web_Liquidacion_Definitiva0-main](https://github.com/Santi-a-ux/Web_Liquidacion_Definitiva0-main)

**Descripción / Description:**
- 🇪🇸 Sistema web completo para automatizar el cálculo de liquidaciones laborales según la legislación colombiana. Incluye gestión de empleados, cálculos automáticos de cesantías, vacaciones, prima de servicios, y generación de reportes avanzados.
- 🇬🇧 Complete web system to automate employee severance calculations according to Colombian labor law. Includes employee management, automatic calculations of severance pay, vacations, service bonuses, and advanced report generation.

**Stack Tecnológico / Technology Stack:**
- **Backend:** Python, Flask
- **Database:** PostgreSQL (Neon Cloud)
- **Frontend:** HTML5, CSS3, JavaScript
- **Testing:** pytest, Selenium, Cypress
- **Quality:** SonarQube (85%+ coverage)
- **Security:** SQL injection prevention, input validation, audit system

**Características Destacadas / Key Features:**
- ✅ Sistema de autenticación con roles (Admin/Asistente)
- ✅ CRUD completo de empleados y liquidaciones
- ✅ Cálculos automáticos con legislación colombiana
- ✅ Dashboard administrativo con estadísticas
- ✅ Exportación de reportes en CSV
- ✅ Sistema de auditoría completo
- ✅ 250+ pruebas automatizadas
- ✅ Arquitectura MVC bien estructurada

**Valor para Empresas / Business Value:**
- Automatiza procesos manuales propensos a errores
- Reduce tiempo de cálculo de liquidaciones en 90%
- Garantiza cumplimiento legal
- Genera reportes para análisis financiero
- Escalable y mantenible

**Métricas de Calidad / Quality Metrics:**
- 4 stars ⭐
- 85%+ código cubierto por pruebas
- 1 fork
- Documentación completa
- Commits regulares y organizados
